프로그래머스(school.programmers.co.kr)에서 문제를 풀 때 "코드 실행"이나 "제출 후 채점하기"를 누를 때마다, 그 문제의 설명 · 내가 작성한 코드 · 실행/채점 결과를 자동으로 내 GitHub 저장소에 커밋해주는 확장 프로그램입니다.

■ 왜 필요한가요?
코딩테스트를 준비하다 보면 "이 문제 저번에 어떻게 풀었더라", "얼마나 많이 풀었지" 같은 걸 나중에 되돌아보기 어렵습니다. 매번 손으로 코드를 복사해서 저장소에 옮기고 커밋 메시지를 쓰는 것도 귀찮고요. 이 확장 프로그램은 그 과정을 통째로 자동화해서, 문제를 푸는 것에만 집중하면 풀이 기록이 알아서 GitHub에 쌓이도록 해줍니다.

■ 주요 기능
- "코드 실행"과 "제출 후 채점하기" 버튼을 누를 때마다 자동 커밋
- 문제 번호, 제목, 난이도, 분류(탐욕법·완전탐색 등 프로그래머스 태그 기준), 문제 링크를 정리한 README 자동 생성
- 작성한 코드를 언어에 맞는 확장자(.c, .cpp, .py, .java 등)로 저장
- 실행/채점 결과를 분석해 "테스트 통과" 여부를 자동으로 표시
- 저장소 루트에 전체 풀이 현황(총 문제 수, 난이도별 통계, 문제별 상태 표)을 담은 README를 자동으로 갱신
- 팝업에서 최근 커밋 기록 확인 및 개별/전체 삭제
- 확장 프로그램 켜기/끄기 토글

■ 사용 방법
1. GitHub에서 저장소 하나를 만들고(비어있어도 됨), Contents 권한을 가진 Personal Access Token을 발급
2. 확장 프로그램 아이콘 → 설정에서 토큰과 저장소 주소 입력
3. 프로그래머스 문제 페이지에서 평소처럼 코드를 실행/제출하면 끝

■ 개인정보 및 보안
- GitHub 토큰과 설정은 브라우저 로컬(chrome.storage.local)에만 저장되며, 개발자를 포함한 어떤 제3자 서버로도 전송되지 않습니다.
- 코드와 문제 정보는 오직 사용자가 직접 설정한 GitHub 저장소로만 전송됩니다.
- 광고, 분석 툴, 원격 추적 코드가 전혀 포함되어 있지 않습니다.

■ 안내
- 이 확장 프로그램은 프로그래머스(그렙)와 관련이 없는 개인(학생) 제작 비공식 도구입니다.
- 오픈소스로 공개되어 있어 누구나 소스코드를 직접 확인할 수 있습니다.
